# Aula del IFD de El Colorado · Alicia y Simón

Una aula de noche con un escritorio compartido: Simón (psicoanálisis) con su pila de libros, Alicia (formación docente) con su computadora, un pizarrón verde con la proyección «Formación Docente» y una ventana por la que se ve la noche.

## Publicar en GitHub Pages
1. Creá un repositorio público y subí los **tres archivos juntos** (`index.html`, `simon.html`, `alicia.html`) con *Add file → Upload files*.
2. En *Settings → Pages*: *Deploy from a branch*, rama `main`, carpeta `/ (root)`.
3. Abrí `https://TU_USUARIO.github.io/NOMBRE_DEL_REPO/`, tocá «Hablar con Simón» o «Hablar con Alicia» y permití el micrófono.

## Notas
- Los agentes son públicos (sin autenticación). Si usás lista de dominios en ElevenLabs, agregá `TU_USUARIO.github.io`.
- Se habla con uno por vez: al activar a uno, el otro se corta.
- Necesita internet (Three.js y la voz de ElevenLabs). Cada conversación consume créditos.
- No abre desde `file://`: el micrófono exige una dirección https.
